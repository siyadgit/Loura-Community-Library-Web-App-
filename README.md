
# 📚 OpenLibrary – Community Book Sharing

A community-powered digital library built with HTML, CSS and JavaScript.

## Features
- Upload books
- Download books
- Search by title and author
- Book categories
- Responsive design
- Supabase cloud storage
- Real-time library updates

## Technologies
- HTML5
- CSS3
- JavaScript
- Supabase

## Installation
1. Clone this repository.
2. Configure your Supabase project URL.
3. Configure your Supabase anon key.
4. Open index.html in your browser.

## Deployment
Deploy using GitHub Pages.
